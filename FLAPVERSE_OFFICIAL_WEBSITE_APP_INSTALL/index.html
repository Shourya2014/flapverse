FAQ

Can I play FLAPVERSE without downloading it?

Yes. Use the Play in Browser button and the game opens directly in the website launcher.

Can I install FLAPVERSE like an app?

Yes. On supported browsers, press Install FLAPVERSE and the game installs with its own icon and standalone app window. You do not need to handle an HTML file or ZIP folder.

Does the global leaderboard work yet?

The leaderboard interface and connection logic are ready, but worldwide rankings require the Supabase project URL and public anon key to be connected.

Does this work on phones?

Yes. Android users can install the PWA from Chrome when supported. On iPhone/iPad, open the site in Safari, tap Share, then Add to Home Screen.
